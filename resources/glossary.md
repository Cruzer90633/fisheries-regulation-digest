# Glossary

Regulatory terms in plain English. Used to keep summaries readable and consistent.

> **Status: draft.** Definitions here are working explanations for readers, not legal
> definitions. Verify each against the agency's own usage before publishing, and link
> to the official definition where one exists.

| Term | Plain English |
| --- | --- |
| ACL | Annual Catch Limit — the most that can be caught from a stock in a year. |
| AM | Accountability Measure — what happens if a catch limit is exceeded. |
| Amendment | A significant, lasting change to a fishery management plan. |
| ASMFC | Atlantic States Marine Fisheries Commission — coordinates state-water rules. |
| EEZ | Exclusive Economic Zone — federal waters, 3 to 200 nautical miles offshore. |
| Effective date | The date a rule starts applying. |
| Final rule | A rule that is settled and takes effect. |
| FMP | Fishery Management Plan — the rulebook for a fishery. |
| Framework action | A faster, narrower change to an existing plan. |
| GARFO | NOAA Fisheries Greater Atlantic Regional Fisheries Office. |
| MAFMC | Mid-Atlantic Fishery Management Council. |
| Possession limit | How much of a species a vessel may have on board. |
| Proposed rule | A draft rule open for public comment. Not yet in effect. |
| Quota | The share of catch allocated to a group, state, or sector. |
| Quota transfer | Moving quota from one holder to another. |
| Specifications | The catch limits and related numbers set for a fishing year. |
| Trip limit | How much may be landed from a single trip. |
