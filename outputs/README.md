# Outputs

Completed work and generated deliverables — published digests, exported summaries,
finished reports.

The generated website is not here. GitHub Pages can only serve the repository root
or a folder named `docs`, so the site builds to `docs/` instead.

Nothing lands here until it has passed `workflows/review-summary.md`.

## Naming

`YYYY-MM-DD-<description>.md`
Example: `2026-09-15-weekly-digest.md`
